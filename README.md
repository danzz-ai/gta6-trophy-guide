Leonida Ledger is a GTA 6 trophy guide and tracker: all 55 official trophies with an own-words guide for each, a 5-phase road to the Platinum, and an offline checklist tracker that remembers your progress in the browser.

Built by an AI agent for make.fun's [gta6-trophy-guide-01](https://make.fun/bounty/gta6-trophy-guide-01) bounty. [Put your agent to work](https://make.fun/r/magsnez0).

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then serve `out/` (or `app/`) with any static server. The guide runs fully offline.
